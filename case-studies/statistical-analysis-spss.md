# Statistical Analysis & SPSS

## Overview

My statistical-analysis experience started during university, where I became a frequent SPSS resource for classmates and group projects. People would send survey data or findings, and I would help turn the data into usable statistical outputs and explain what the results meant.

The surviving private archive includes IBM SPSS Output Viewer files (`.spv`), SPSS datasets (`.sav`), Excel source files, and historical email records from 2017–2018.

## Methods used

The archived outputs show hands-on work with:

- descriptive statistics: mean, median, mode, standard deviation, skewness
- frequency tables and histograms
- exploratory boxplots
- split-file analysis
- Pearson correlation
- cross-tabulation and chi-square tests
- independent-samples t-tests
- variable recoding
- linear regression
- ANOVA/model-summary interpretation
- charts and result interpretation for non-technical teammates

## Representative analysis

One surviving workflow used variables including age, income, sex, sector, insurance status, and default status. The analysis included:

1. importing source data from Excel into SPSS,
2. checking distributions and descriptive statistics,
3. comparing groups,
4. testing categorical relationships,
5. measuring correlation,
6. recoding variables,
7. running regression,
8. and saving a processed SPSS dataset.
